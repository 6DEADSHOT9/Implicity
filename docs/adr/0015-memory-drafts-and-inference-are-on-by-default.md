# Memory, deleted drafts and state inference are on by default

All three are switched on at onboarding, where the person agrees on one screen with a switch for each. Opt-in would be the cautious default; on-by-default was chosen deliberately, with consent taken once, up front. The safeguards are a visible chip whenever something remembered or noticed shaped an answer, one-tap correction, a temporary chat that captures nothing, and separate resets.

## Consequences

Deleted draft text is sent to the remote model with that turn, because only the model can interpret it. Health-related inference is the exception and stays off until the person turns it on.
